# Figuras de regresion

Practica de IA en R. Tres modelos de regresion sobre el dataset `airquality` (viene incluido en R, no hay que descargar nada): lineal simple, lineal multiple y polinomial, cada uno con su grafico hecho en ggplot2.

La variable a predecir en los tres es el ozono. El polinomial crea los terminos de grado 2 a 4 de la temperatura a mano y dibuja la curva sobre una malla fina para que salga suave.

## Requisitos

R o RStudio con ggplot2 instalado.

## Uso

```r
source("P12.R")
```
